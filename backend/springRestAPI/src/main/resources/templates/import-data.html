Instructions

CSV Format Requirements:

  • Devices CSV: Columns: device_unique_id, type_name, brand_name, model, serial_number, purchase_date, warranty_period, notes
  • Rooms CSV: Columns: room_number, room_name, building, floor, capacity
  • Installation History CSV: Columns: device_unique_id, room_number, installation_date, installation_time, installer_name, installer_id, withdrawal_date, withdrawal_time, withdrawer_name, withdrawer_id, data_entry_by, status, notes
  • Gate Passes CSV: Columns: gate_pass_number, device_unique_ids, pass_direction, gate_pass_date, gate_pass_time, department, gate_name, vendor_destination, bearer_name, bearer_company, bearer_contact_no, security_officer_name, security_officer_designation, security_officer_ext, processing_name, processing_designation, processing_ext, authorized_name, authorized_designation, authorized_ext
  • First row must be header row with column names
  • Date format: YYYY-MM-DD (e.g., 2025-01-15)
  • Time format: HH:MM (e.g., 14:30) - Leave empty if not applicable
  • For Gate Passes: device_unique_ids can be comma-separated for multiple devices. pass_direction must be 'incoming' or 'outgoing'
  • For Installation History: status should be 'active' or 'withdrawn'. Leave withdrawal fields empty for active installations
  • File must be in CSV format (.csv extension)
